rubevy games

Two samples of rubevy: Bevy for the rules, SabiRuby for the behaviours. Both run here — the Ruby is compiled in the page and runs in the same VM the PC build uses.

  • SabiRuby Battle Four robots fight; each one's behaviour is a Ruby task you can edit and re-apply while the match runs.
  • Garden A small world whose creatures read and write their own ECS components from Ruby (me[:Hunger]), breed, remember, and can be saved and loaded.

SabiRuby Battle used to be at this address itself; it moved to /sabibots/ when the garden arrived, and this page took its place.
