## 1. (6) 前任の差分 — `--shot` と判定を同時に、`fixedlines.sh` の CR

### 何が置いてあったか

`git diff` の 6 ファイルは 2 つのことをしていた。

1. **`games_shell::checks::checks_end_the_run()`**（新）。今まで判定の終わりは
   `CHECKS_EXIT_WHEN_DONE`（PC は `true`、ページは `false`）だけを見て `AppExit` を書いていた。
   `--shot FILE SECONDS` は窓を開けて待って 1 枚撮って出るので、判定が済んだ瞬間にアプリが終わる
   PC では絵の時刻が来る前に窓が閉じる（F0 §10 の 4 件目。`--shot g.png 30` が 9 秒で閉じて
   ファイルを 1 枚も書かなかった）。新しい関数は「この走行がほかに何か頼まれているか」を
   `crate::args::Args::from_env()` で見て、`--shot` があれば `false` を返す。
   利用側は garden と sabibots の `platform.rs`（`pub use` の差し替え）と、
   `garden/src/window.rs` / `sabibots/src/main.rs` の `if` 1 行ずつ。
2. **`tools/fixedlines.sh` が CR を先に落とす**。`docker/run.sh` は `-t` 付きなので窓の走行の行は
   `\r` で終わり、`grep -o 'selftest: .*'` が切り出す行にその CR が入る。比べると 32 行全部が
   違うと言われる。`cat "$@" | tr -d '\r' | grep -o …` に。

### 確かめたこと

**CR**: 合成のログで実測した（本物の窓の走行は下のとおり回せない）。同じ 6 行を、素のものと
`sed 's/$/\r/'` を掛けたもので作り、前の版（`git show HEAD:tools/fixedlines.sh`）と新しい版に
掛けた。

| | 素のログ vs CR 入りのログ |
|---|---|
| 前の版 | **4 行全部が違う**（`1,4c1,4`） |
| 新しい版 | **diff 空** |

そして「前の版に素のログ」と「新しい版に素のログ」も diff 空 — CR の無いログに対する出力は
S9 の前と 1 バイトも変わっていない。これが「道具の振る舞いを変えると過去の比較と揃わなくなる」
（F0 §10 の 2 件目が触らなかった理由）への答えになっている。

**`--shot`**: **実物の走行では確かめられていない。** この機械には窓が開けられない — `docker info` は
segmentation fault で落ち（Docker Desktop は起動しない約束）、host には Vulkan の ICD が無く
（`/usr/share/vulkan/icd.d` そのものが無い）、`WGPU_BACKEND=gl LIBGL_ALWAYS_SOFTWARE=1` でも
bevy_render は `Unable to find a GPU!` で panic する。`--shot` は窓の走行なので、
`GARDEN_SELFTEST=1 … --shot g.png 30` を走らせると窓が開く前に落ちる。

できるのは規則そのものを試すことなので、`checks_end_the_run` を**引数を渡す形に割って**
（`fn checks_end(args: &Args)`、公開の側は `Args::from_env()` を渡すだけ）、単体テストを 1 本足した:
`--shot` の無い行と `--headless 90` では `true`、`--shot` と `--shot g.png 30` では `false`、
`--shots`（前置きが同じだけの別の語）では `true`。`Args::has` は語全体の比較なので最後の 1 つが通る。

**未実施**: 絵が本当に出ること、判定と `--shot` が同じ走行で両立すること。窓が開く機械で
`GARDEN_SELFTEST=1 docker/run.sh garden release --shot g.png 30` を 1 回回せば済む。
