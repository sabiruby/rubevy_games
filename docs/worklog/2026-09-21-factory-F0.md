`[patch.crates-io]` の SabiRuby の 3 つ（`sabiruby` / `sabiruby-compiler` / `sabiruby-serde`）の rev は
動いていない（`git diff Cargo.lock | grep sabiruby` が拾うのは rubevy の依存の行だけ）。ほかに動いた行は
`windows-sys` が 0.60.2 → 0.61.2 に解決し直した 3 か所で、これは Windows 専用の依存であり
この機械では 1 度も建たない。S7 のときはこれが逆向き（0.61.2 → 0.60.2）に動いていて、今回はそれが

**途中で 1 つ引っかかった**: 窓の走行だけ 32 行すべてが違うと出た。原因は `docker/run.sh` が
`-t` を付けて走らせるので出力の各行が `\r` で終わることで、`fixedlines.sh` はそれを落とさない。
`tr -d '\r'` を通したら 2 本とも `diff` が空になった。**ゲームの話ではなく比較の道具の話**なので
ここには直さずに書いておく（報告の「気づいた点」にも）。
