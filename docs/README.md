# rubevy_games documents

Laid out as every repository of the organization is
([`.github/CONTRIBUTING.md`](https://github.com/sabiruby/.github/blob/main/CONTRIBUTING.md));
small enough to stay flat; plans, and now the standards a run is held to, have their own directory.

**The standard a run of the checks is held to is
[verification/selftest-lines.md](verification/selftest-lines.md)** — the list of lines each of the
six runs prints, and `tools/fixedlines.sh`, which is how two runs are compared. It replaces the
bare counts ("the garden: ok 43", "Battle: 31 fixed lines plus two a hit") that the worklog rows
below quote: those are what each of those runs recorded on its own day and are left as they were
written, but a number does not say which lines, and a number is not something a later run can be
checked against.
